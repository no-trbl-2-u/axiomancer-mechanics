# Deck Tuning — Card Forge — 2026-07-02 (`--focus="Early"`)

## Headline finding

**The early-stage tier-1 pool has ZERO `direct-dot` verb-class cards.** Every
DoT effect in the Effects library (`debuff_bleed`, `debuff_poison`,
`debuff_burn`, `debuff_acid`, ...) is tagged `tier: 2` or higher, and the
early stage profile (`COMBAT_STAGE_PROFILES.early`, `maxCardTier: 1`) gates
every card whose own `tier > 1` out of `stageEligibleCardIds`. Result:
`dotFrac` measures exactly **0%** across every early cell, every policy,
confirming the finding already flagged (but not root-caused) in the
balance-bands test comments (`greedyDotHpFractionMin: 0.0 // FINDING: early
enemies die before a DoT tick lands`). This is a genuine early-game
degenerate-to-basic-attack-trading risk per doctrine.

Forged a sandbox card (`sandbox-paper-cut-argument`, tier 1, composes the
EXISTING `debuff_bleed` effect at weak intensity/duration) to prove the fix.
It closes the gap decisively in isolation — but a same-PR promotion attempt
into `cards.library.ts` broke three PINNED balance-band assertions via a
seed/RNG-entanglement mechanism unrelated to the card's own power level (see
"Considered but not applied" below). **Recommendation: keep sandboxed this
tick; promotion needs a coordinated recalibration pass, not a cold edit.**

## Considered but not applied: library promotion

Per the promotion path (>= 2 stages, >= 2 policies proven), also ran the
early-dot-pilot card at `--stage=mid --policy=blind` for the second-stage
leg. In isolation (sandbox only) this was clean. To fully validate
promotion, moved the literal into `cards.library.ts` (as `paper-cut-argument`,
tier 1) in a working copy and bumped the card-coverage pin (65 → 66), then
ran the actual balance-bands contract
(`combat-playtest.balance-bands.sim.test.ts`, unchanged thresholds, seed 1):

```
FAIL the impossible fight is NEAR-impossible, not scripted-unwinnable: greedy scrapes 1-5% at 200 seeds
  → the ceiling became scripted-unwinnable: expected 0 to be greater than 0
FAIL CANARY: random play (chaos) currently CRACKS the ceiling via the free turn-cycling weaken/deny loop
  → the turn-cycling exploit seems fixed — flip this canary: expected 0 to be greater than 0
FAIL stage-summary statusEngagement clears the floor on every non-impossible stage
  → statusEngagement floor broken on 'mid': expected 0.18799... to be greater than 0.2
```

**Root cause: NOT the card's power level.** Because a tier-1 card is
eligible in every stage's draft pool (`early`/`mid`/`late`/`impossible` all
have `maxCardTier >= 1`), adding one candidate to the shared weighted-draft
pool shifts the deterministic RNG stream for every subsequent seeded draw —
including on stages the card was never designed to touch. The pinned
balance-band literals (`STAGE_BANDS`, `IMPOSSIBLE_GREEDY_WIN_MAX`) are
calibration anchors keyed to the EXACT seed-1 sequence over the CURRENT
65-card library; any library-shaped change (this one included) perturbs them
via this entanglement, independent of whether the change is good, bad, or
neutral for play. `impossible`'s greedy win rate moved from ~0.015-0.025 to
exactly 0 (masks the canary rather than fixing it) and `mid`'s
statusEngagement dropped from ~0.283 to 0.188 — neither is a real
regression in play quality, both are seed-stream artifacts.

**Action taken: reverted the promotion** (`git checkout --` on
`cards.library.ts` and the coverage-pin test) per the skill's hard rule
("never bypass `npm run verify`... a change that breaks a test is reverted").
`sandbox-paper-cut-argument` stays SANDBOX-ONLY this tick — the sandbox path
is provably good; shipping it needs a coordinated recalibration pass (rerun
and re-pin `STAGE_BANDS` / `IMPOSSIBLE_GREEDY_WIN_MAX` against the 66-card
library in the SAME change as the promotion) rather than a cold promotion
into an untouched, differently-calibrated contract. Flagging for the next
`/deck-tuning` tick (or a coordinated `/deck-tuning` + `/combat-tuning`
pairing) to promote-and-recalibrate together.
